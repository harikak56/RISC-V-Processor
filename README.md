# RISC-V Processor

A 32-bit RISC-V processor implemented in SystemVerilog using Vivado 2025.2.

## Architecture
The processor is organized into instruction fetch, instruction decode,
execution, memory access, and write-back stages.

## Modules
- Instruction Fetch and Instruction Memory
- Instruction Decoder and Control Unit
- Register File and Immediate Generator
- ALU and ALU Control
- Branch Unit
- Data Memory
- Top-Level Processor

## Tools
- Xilinx Vivado 2025.2
- SystemVerilog

## Simulation
The design includes a testbench for behavioral simulation.
